# Hogwarts-manager

Менеджер персонажа в мире Гарри Поттера — фан-проект в духе dpm.lol: предыстория,
распределение по факультетам, случайные события со взвешенным риском, экономика
(деньги и оценки), клубы, питомцы, дружба/отношения, мини-игра рисования
заклинаний и чтение лекций перед экзаменами.

Это MVP: полностью реализован первый курс (распределение → учебный год →
экзамены → итоги). Переход на следующие курсы и выбор профессии — в roadmap.

## Стек

- **Сервер**: Node.js, Express, TypeScript, better-sqlite3, JWT-авторизация.
- **Клиент**: React + TypeScript + Vite, без внешних UI-библиотек (свой
  пергаментно-готический стиль).

## Запуск локально

```bash
# Сервер (порт 4000)
cd server
npm install
npm run dev

# Клиент (порт 5173, с проксированием /api на сервер)
cd client
npm install
npm run dev
```

Откройте http://localhost:5173, зарегистрируйтесь и начните игру.

База данных SQLite создаётся автоматически в `server/data/hogwarts.db`.
